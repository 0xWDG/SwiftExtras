# SwiftExtras iOS Demo

Open `SwiftExtrasiOSDemo.xcodeproj` in Xcode, select an iPhone or iPad
simulator, and run the `SwiftExtrasiOSDemo` scheme.

The project links the local SwiftExtras package from the parent directory and
shares its demo source files with the macOS Swift Package executable. Regenerate
the project after changing its structure with:

```sh
ruby generate_project.rb
```
